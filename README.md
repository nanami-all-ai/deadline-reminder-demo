# 締め日と資料提出リマインド日の一覧（1画面デモ）

Claude Codeで作成（七海）。

## できること
- 顧客ごとに「締め日（毎月N日／月末）」と「締め日の何営業日前にリマインドするか（例：3,1）」を入れると、基準月（既定は今月）と翌月の送信日を、送信日順の一覧にする。
- 営業日は土日・日本の祝日・年末年始（12/29〜1/3）を除いて数える。締め日当日は数えず、その前の営業日から遡る。
- 一覧の行ごとに、定型文の下書き（顧客名・締め日・資料名を差し込み）をコピーできる。一覧のCSV書き出しもできる。

## 使い方
1. `index.html` をブラウザで開く（サンプルは架空。「サンプルを消す」で空になる）。
2. 顧客名・締め日・何営業日前か（カンマ区切り）を入れ、「一覧にする」を押す。
3. 一覧の「文面コピー」で下書きをコピーして使う。必要なら「CSVで書き出す」。

## 限界
- 祝日は2026〜2027年の固定リスト。それ以外の年が関わる日付は、行に「祝日未登録」の警告を出す（祝日を考慮せず土日と年末年始だけで計算）。
- 年末年始は12/29〜1/3を一律で休みとして扱う。顧客ごとの休業日・独自の休みは扱わない。
- 「毎月31日」のように月にない日は月末に丸める（警告を出す）。「第○営業日締め」「翌月N日締め」には対応しない。
- 自動送信はしない。文面のコピーと日付の一覧だけ。
- 入力は画面内で処理するだけで、保存も外部送信もしない（再読み込みで消える）。依存なしの単一HTML。

## 未検証の点
- 祝日リスト（2026年18日・2027年17日）は2026-10-04に一次ソースと1日ずつ突合し、全件一致（誤り・漏れなし）。内閣府「国民の祝日」CSV https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv ／内閣府 https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html ／国立天文台 令和9年暦要項 https://eco.mtk.nao.ac.jp/koyomi/yoko/2027/rekiyou271.html 。2027年は春分3/21・秋分9/23・振替休日3/22を確認済み（9/22は国民の休日ではない）。2026年は5/6振替休日・9/22国民の休日を確認済み。なお、CSVの文字コードがShift_JISで取得ツール上は文字化けし、日付のみ照合した（祝日名は内閣府gaiyouページで確認）。2028年以降は未登録（画面に警告が出る）。
- 検算（verify.mjs）は営業日逆算のロジックが対象で、祝日リストの正しさは検証していない（振替休日の登録漏れの簡易チェックのみ）。
- 画面操作は2026-10-04にPlaywright（scraper/node_modulesのplaywright＋手元のGoogle Chrome、ヘッドレス、file://、幅375px）で実機確認済み。確認できた内容：①顧客2件（毎月25日／月末、3・1営業日前）、基準月2026-10で8行が日付順に出て、画面のテキストがverify.mjsと同じ計算（index.htmlのCALC部分）の期待値と全行一致、月末選択時は「日」欄が無効化、②『文面コピー』はクリップボード書き込みを失敗させた状態（navigator.clipboardを失敗する関数に差し替え）で下書き欄に差し込み文が出てボタンが「下書き欄に出しました」に変わる、③CSVはファイル先頭がEF BB BF（BOM）、顧客名が=で始まるセルに'が付く、④基準月2027-12で「祝日未登録の年（2028年）」の警告と該当4行に印、⑤幅375pxで横スクロールなし（scrollWidth=375）、⑥コンソールエラー0件。スクリーンショットは scratch/deadline-reminder-mobile-375.png。
- 画面操作で未確認：実ブラウザでの実際のクリップボード書き込み成功側、Excel等での開き方、Safari・Firefox・実機スマホ、ダークモードの見た目。
- 実際の顧客データでの動作は未検証（架空データのみ）。
